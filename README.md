# TVApp

## how to run

Open the App and wait. 
It will automatically load 250 list of shows. 
You can click or tap the show images to go in to detail page.
On the detail page you can see the show information and at the right bottom corner of the screen there is a button.
That button will open another pop up to select share method. 
the message is like this : 

Check out this show!

"show name"
Rating: "number"
Summary: "paragraf"

"url page"
